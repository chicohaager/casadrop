1 What CasaDrop does for you

CasaDrop turns a file into a link. You drop a file into the browser, CasaDrop gives you a URL, and whoever holds that URL can download the file — no account, no app, no sign-up on their side. It works the other way round too: you can hand out an upload page so somebody else can send files to you.

Send

Upload a file or a whole folder's worth of files and get a link for each one. Optionally protect it with a password, let it expire after a set time, or let it die after N downloads.

Receive

Create a receive link and send it to someone. They get a simple upload page — no account needed — and you get the files, within the limits you set.

Browse

Share a whole folder and the recipient gets a browsable listing with breadcrumbs, per-file downloads and a “Download All as ZIP” button.

Preview

Images, video, audio and PDFs play or render right on the share page, so a recipient can look before downloading.

Who can do what depends on your role. Admin, User and Viewer see different things. If a button described here is missing for you, check §9 Roles and storage quota before assuming something is broken.

2 Signing in

Open the address your administrator gave you. If you are not signed in yet, CasaDrop sends you to its login page.

Leaving the email blank is not a shortcut for a personal account. A blank email means “use the single shared admin password”. If you have your own account and leave the email out, your password will simply be rejected.

If the login page keeps rejecting you

  • CasaDrop rate-limits sign-in attempts (5 per minute from one address) and locks an account for 15 minutes after 10 failures. If you have been guessing, wait it out — a correct password will still fail while the lock is active.
  • A session lasts up to 24 hours of inactivity and is refreshed while you work, with a hard ceiling of 7 days. After that you sign in again. That is normal, not a fault.

Language and theme

At the bottom of the sidebar, above Logout, sit two controls:

  • A language dropdown. CasaDrop ships 14 languages — English, Deutsch, Français, Español, Italiano, Português, Nederlands, Polski, Русский, 日本語, 中文, 한국어, Türkçe and العربية. It starts in your browser's language and remembers your pick in that browser.
  • A Dark Mode / Light Mode button. Also remembered per browser.

Both reload the page when you change them — that is by design, not a glitch. Neither setting follows you to another device: they live in the browser you are sitting at.

Above them, a small badge shows your name and your role. That badge is the fastest way to answer “why can't I see that button?”.

4 Sending a file

  1. Open Upload and either drag files onto the drop zone or click it to open a file picker. You can select several files at once. There is also an Upload Folder button inside the drop zone.
  2. Set the options that appear once files are queued — password, expiry and download limit (all described below). They apply to every file in this batch.
  3. Click Upload. A progress bar runs per file.
  4. Copy the links. When it finishes, each file gets its own share URL of the form /s/<id>. Copy them now, or find them any time under Shares.

“Upload Folder” does not create one folder share. It is a convenience for selecting everything in a folder; each file is uploaded separately and gets its own link. If you want one browsable link for a whole directory, that is a folder share — see §8 (admin) or ask your administrator.

The three upload options

OptionWhat it does
Password
optional		 The recipient must type this password before they see or download anything. Leave empty for a link that works for anyone who has it. There is no way to read the password back later — if you forget it, edit the share and set a new one.
Expires in How long the link stays alive. The choices are 1 hour, 6 hours, 12 hours, 1 day (default), 3 days, 7 days, 14 days, 30 days, or Never (unlimited). After expiry the link is dead and the file is cleaned up automatically.
Max downloads Retire the link after this many downloads. 0 means unlimited. Useful for “this is for you and nobody else”: set it to 1.

Large files just work. Anything over 100 MB is uploaded in 8 MB chunks automatically, which survives flaky connections and proxies that dislike huge single requests. You do not switch anything on; the progress bar looks the same.

If an upload fails

A failed upload says so: the bar turns red and prints “Upload failed” with the reason underneath. Server unreachable means the connection died — check that you are still on the network and that the instance is up. A message quoting an HTTP status came from the server, and the most common reasons are the file type being blocked by your administrator, or your storage quota being full (§9).

5 Managing your shares

The Shares view lists everything you have shared, with a statistics bar at the top (total shares, downloads, total size, how many are password-protected). Administrators see everybody's shares; a User sees only their own.

Reading a share card

Each card shows a thumbnail (for images), the file name, and a row of facts: download count, size, and when it expires. Three badges may appear:

Protected needs a password  ·  Folder a browsable folder share  ·  Expiring less than an hour left

The buttons on each card

ActionWhat happens
Copy linkPuts the share URL on your clipboard and confirms with a toast.
QR CodeShows a QR image of the link — the quickest way to move a file to a phone standing next to you.
EditChange the expiry, the download limit, and add, change or clear the password after the fact.
Send via EmailMails the link to a recipient with an optional message. Only works if your administrator has configured SMTP.
Send to device (Taildrop)Pushes the actual file to one of your Tailscale devices. The button only appears when Tailscale is running on the server, and never for folder shares.
DeleteKills the link and removes the uploaded copy. Asks for confirmation first. Not undoable.

Clearing out several at once

Each card has a checkbox. Tick a few — or use Select All — and a Delete Selected button appears in the header with a count next to it. Same warning applies: deletion is immediate and final.

6 What the recipient sees

Worth knowing, because it is what you are actually sending people. Your recipient needs no account and no login.

A single file — /s/<id>

  • The file name, its size, when it expires, and its type.
  • A preview where the format allows: images render, video and audio get a player, PDFs open in a frame.
  • A big Download button and a QR button (“Scan to download on another device”).
  • If you set a password: a lock screen — “Password Protected — Enter the password to access this file” — with an Unlock button. Nothing about the file, not even the preview, loads until the password is accepted.

MKV files play only partly in browsers. If you share a Matroska video, the page says so itself: audio tracks in AC-3, E-AC-3 or DTS have no browser decoder, so the picture may run silently. The download is unaffected — tell your recipient to download rather than stream.

A folder — /s/<id> with a listing

  • A table of Name and Size, with breadcrumbs to walk into subfolders and back.
  • Any single file downloads on click.
  • A Download All as ZIP button builds the archive on the fly. Very large folders can hit a size ceiling set by your administrator.
  • The same password gate as above, worded “Enter the password to browse this folder”.

7 Receiving files from others

A receive link is the mirror image of a share: you publish a page, somebody else uploads to it. They need no account. This is the right tool for “send me the scans” instead of asking people to email attachments.

Creating one

  1. Go to Receive and click New Link.
  2. Give it a Name — the only required field. It is for your own orientation in the list.
  3. Set the limits you want (all optional, all described below).
  4. Click Create. You get a URL of the form /r/<id>. Send that to whoever should upload.
FieldEffect
PasswordUploaders must enter it before the upload form appears.
Max uploadsTotal files this link will ever accept. 0 = unlimited. The page shows a live counter, e.g. 2 / 10 uploads used, and switches to Upload Limit Reached when full.
Max file size (MB)Per-file ceiling. 0 = unlimited.
Expires in (hours)0 = never. After it passes the link stops accepting uploads.
Allowed extensionsA whitelist, comma-separated, e.g. .pdf,.doc. Anything else is refused with a plain message — an attempted .exe against a .txt-only link is told “File type .exe not allowed”. Leave empty to accept whatever your instance allows generally.
Auto-share uploaded filesEvery arriving file immediately gets its own share link, so you can pass it on without a second step.

What your uploader sees

A single card: the limits spelled out, the counter if you set one, a password box if you set one, then “Drag & drop a file here / or click to browse” and an upload button. On success: “File Uploaded Successfully”. Nothing else on your instance is reachable from that page.

Two protections may be active without you doing anything. Your administrator can switch on virus scanning (an infected file is rejected outright) and a small proof-of-work puzzle the browser solves before uploading, to blunt automated abuse. The puzzle needs an HTTPS connection to work; on a plain-HTTP LAN address a per-address rate limit does the same job. Neither needs anything from your uploader beyond a moment's wait.

Collecting what arrived

Open the link's card under Receive to see the files that came in and download them. Deleting the receive link deletes its received files with it.

8 Sharing what is already on the server

Admin only — if you do not see Share from host in the sidebar, you do not have this, and the server will refuse the request even if you find the URL.

Use it when the file is already on the machine CasaDrop runs on — a video on the NAS, a folder of photos — and re-uploading it would be absurd.

  1. Open Share from host. You get a file browser, restricted to the directories your administrator allowed. Image files show a thumbnail so you can tell them apart at a glance.
  2. Walk to the file or folder using the breadcrumbs.
  3. Click Share on the row you want.
  4. In the dialog, decide whether to tick “Link instead of copy (no extra disk space)”, then confirm.

Link or copy? A link serves the original file where it lies — no extra disk space, and it does not count against a storage quota, but if the original is moved or deleted the share breaks. A copy is independent of whatever happens to the original afterwards, and it does consume managed storage.

Sharing a directory produces a folder share: one link, a browsable listing, and a ZIP download for the recipient (§6).

Host browsing and host sharing (§8) are restricted to Admin regardless of the table above.

Your storage quota

An administrator can cap how much managed storage your account uses. When you exceed it, an upload is refused with “Storage quota exceeded”. What counts and what does not:

Counts against you

  • Files you uploaded
  • Host files shared as a copy
  • Files other people upload through your receive links

Does not count

  • Host shares created as a link
  • In-place folder shares

Watch the third item on the left. Uploads made by strangers through a receive link you created are billed to your quota, not theirs. A generous public receive link is the usual way to fill a quota without noticing. Set a max file size and a max upload count.

Your own quota and usage are not shown in the sidebar; an administrator can read both in Settings → User Management. If uploads start failing with the quota message, delete some old shares — that frees the space immediately — or ask for a larger allowance.

10 Securing your account

Two-factor authentication

Available for the shared admin login. It adds a six-digit code from an authenticator app — Aegis, Google Authenticator, 1Password and friends — on top of the password.

  1. Go to Settings → Two-Factor Authentication and click Enable 2FA.
  2. Scan the QR code with your authenticator app, or copy the secret shown beneath it into the app by hand.
  3. Type the current six-digit code and click Verify & Enable. A wrong or stale code is refused — the codes rotate every 30 seconds, so take the fresh one.
  4. From now on, fill the 2FA Code field on the login page.

There are no printed recovery codes. Losing the authenticator means losing that login path; recovering it requires access to the server itself. Enrol on a device you back up, or add the same secret to a second device while the QR code is on screen.

API keys

Under Settings → API Keys you can mint a key for scripts and other tools, which they present in an X-API-Key header instead of signing in.

The key is shown exactly once, at creation. Copy it into your password manager in that moment. If you lose it, the only remedy is to delete the key and create a new one.

Habits worth having

  • Treat a share link as the password itself — anyone holding the URL can download the file. If it might get forwarded, add a share password and send it through a different channel.
  • Prefer a short expiry. The default of one day is a sensible default for a reason; “Never” should be a deliberate choice.
  • For a genuinely one-off handover, set Max downloads to 1.
  • Delete shares you are done with instead of waiting for expiry.
  • Sign out on machines that are not yours — the session survives a closed browser window.

11 When something goes wrong

SymptomWhat it usually means
Recipient reports “this page cannot be found” The share expired, hit its download limit, or was deleted. Expiry is enforced strictly and the file is cleaned up afterwards — create a new share.
Upload bar turns red: Server unreachable The connection dropped or the instance is down. Reload the page; if the login screen appears, the server restarted and you simply sign in again.
Storage quota exceeded Your account is at its cap. Delete old shares or ask for more (§9).
File type … not allowed Either the receive link's whitelist, or an instance-wide restriction set by your administrator. The message names the extension it rejected.
No Share from host in the sidebar You are not an admin. This is intentional, not a bug (§8).
No Send to device button Tailscale is not running on the server, or the share is a folder — Taildrop handles single files only.
Send via Email fails SMTP is not configured on the instance. That is an administrator setting.
Video plays but is silent Almost always an MKV with an AC-3/DTS audio track, which no browser decodes. Download the file and play it locally (§6).
Correct password still rejected at login You are inside the rate limit or a 15-minute lockout from earlier failures. Wait, then try once.
The share link works for you but not for the recipient The link carries an address only reachable from inside your network. Ask your administrator which network is set as primary for outside links.

12 Quick reference

The four link shapes you will meet. <id> is the short identifier CasaDrop generates.

/s/<id>     the share page you send to people  (file or folder)
/d/<id>     the direct download of a shared file
/r/<id>     the upload page you hand to someone else
/qr/<id>    a QR image of the share link

Defaults worth remembering: expiry 1 day · max downloads 0 (unlimited) · no password · files over 100 MB upload in chunks automatically · 14 interface languages · sessions idle out after 24 hours and end after 7 days.
